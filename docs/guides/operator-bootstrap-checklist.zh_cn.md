# 操作员 bootstrap 核对清单

**对象：** 验证 fresh-install `esrd` 实际能完成 12 步 bootstrap 流程的操作员（或 reviewer）。
姊妹文档：[`operator-bootstrap-journey.md`](operator-bootstrap-journey.md) 是**怎么做**；
本文是**怎么验证**。

每行三维度评分：

- **Interface (I)** —— 入口点*能*服务这一步
- **Function (F)** —— 端到端真的交付预期行为
- **Grammar (G)** —— 文字与操作员看到的一致

每次 fresh install / 大改 grammar 之后跑一遍。本核对清单背后的审计历史在
[`docs/manual-checks/`](../manual-checks/)。

## 12 步核对

在你的 fresh-install 环境跑下面的命令。每行都打钩才算 install 通过。

### 1. Daemon 起来

```bash
bash scripts/esrd.sh start --instance=default
launchctl print gui/$(id -u)/com.ezagent.esrd-default 2>&1 | grep state
```

- [ ] launchd plist `state = running`
- [ ] `tail -1 ~/.esrd/default/logs/launchd-stdout.log` 看到 Phoenix 启动行

### 2. 第一个 `user_add` 自动 admin

```bash
alias esr-dev='ESRD_HOME=$HOME/.esrd-dev ESR_INSTANCE=default ./runtime/esr'
esr-dev exec user_add --name=<your_name>
```

- [ ] 输出 `action: created`
- [ ] `cat ~/.esrd/default/capabilities.yaml | grep -A2 <your_name>` 显示 `["*"]` 全部权
- [ ] `cat ~/.esrd/default/operator.json` 含 `"username": "<your_name>"`

### 3. 注册 adapter（Feishu）

```bash
esr-dev exec register_adapter --type=feishu --name=esr_helper \
    --app_id=cli_xxx --app_secret=xxx
```

- [ ] 输出 `ok: true`
- [ ] `cat ~/.esrd/default/adapters/esr_helper/config.yaml` 带 `app_secret`（yaml-layout-v2 spec § 4.3）
- [ ] `tail -20 ~/.esrd/default/logs/launchd-stderr.log | grep feishu` 看到 sidecar 启动

### 4. 绑 Feishu 身份

```bash
esr-dev exec feishu_bind --name=<your_name> --feishu_user_id=ou_xxxx
```

- [ ] 输出 `ok: true`
- [ ] `cat ~/.esrd/default/users/<uuid>/user.json | jq '.feishu_ids'` 含你的 `ou_xxxx`

### 5. claude_code plugin 已就绪

claude_code 是 built-in（不用单独装）。验证：

```bash
esr-dev exec /plugin:list
```

- [ ] 列表里有 `claude_code`，标记 enabled

### 6. plugin 配置（proxy 等）

```bash
esr-dev exec /plugin:set plugin=claude_code key=http_proxy value=http://127.0.0.1:7897
esr-dev exec /plugin:show-config plugin=claude_code
esr-dev exec /plugin:reload plugin=claude_code
```

- [ ] `/plugin:show-config` 看到 override
- [ ] `/plugin:reload` 返 `ok: true`

### 7. Feishu 里 `/help` `/doctor` 能用

在装了 bot 的 Feishu chat：

```
/help
/doctor
```

- [ ] `/help` 返渲染好的命令清单（来自 `Esr.Resource.SlashRoute.Registry`）
- [ ] `/doctor` 返 user-binding + chat-binding + bootstrap 指引

### 8. `/session:new` 起 session

Feishu 里：

```
/workspace:new name=test-ws
/session:new name=test-cc
```

- [ ] 都返 `ok: true`
- [ ] `/session:list` 能看到新 session

### 9. `/workspace:add-folder` 给 workspace 加目录

Feishu 里：

```
/workspace:add-folder path=/abs/path/to/repo
```

- [ ] 目录出现在 `/workspace:info`
- [ ] 路径必须真的是 git repo（命令拒非 git 目录）

### 10. `/agent:add` 加 CC agent

Feishu 里：

```
/agent:add type=cc name=alice
```

- [ ] 返 `ok: true` + `actor_ids.cc` + `actor_ids.pty`
- [ ] `/agent:list` 看到 alice
- [ ] 多实例：再 `name=bob` 与 alice 并存

### 11. 普通文本路由到 primary agent 的 Claude Code

Feishu 里（agent 已设 primary）：

```
hello, what's the cwd?
```

- [ ] Claude Code 在 chat 里回显真实 cwd
- [ ] PTY 里看到提示符 + 响应（`/pty:list` 验证）

### 12. `/claude_code:tui` 返可点击 URL

Feishu 里：

```
/claude_code:tui name=alice
```

- [ ] 返 URL 形如 `http://<host>:<port>/ptys/attach?token=<phoenix_signed_token>`
- [ ] URL 不含 actor_id（只有签名 token）
- [ ] 点开浏览器看到 xterm.js 接进 alice 的 PTY
- [ ] Token 10 分钟过期；过期后重新加载 → 403

## 横向核对

不属于 12 步但顺手 spot-check：

### A. drift gate

```bash
cd runtime && mix esr.check_command_docs
```

- [ ] 返 `✅ slash-routes.yaml + docs/grammar/* in sync with command_meta/0`
- [ ] 手改 `slash-routes.default.yaml` 后下次跑应该挂

### B. 裸前缀帮助

Feishu 里：

```
/workspace
/workspace:help
/zzznotreal
```

- [ ] `/workspace` 列方法（workspace:new、workspace:list…）
- [ ] `/workspace:help` 同上
- [ ] `/zzznotreal` 返"未知 resource"提示

### C. 自动生成的 grammar 文档

```bash
ls docs/grammar/
cat docs/grammar/commands.md | head -40
cat docs/grammar/errors.md | head -40
```

- [ ] 两份文件都存在 + 头部带 `<!-- AUTOGENERATED — DO NOT EDIT BY HAND. -->` banner
- [ ] spot-check：`/workspace:new` 的 kind 与其 `command_meta()` 一致

### D. PTY attach 安全

```bash
curl -s "http://<host>:<port>/ptys/attach?token=<expired_token>" -o /dev/null -w "%{http_code}\n"
```

- [ ] 返 `403`（或友好的 invalid-token 页）
- [ ] 不带 token → 也是 403

## 这份清单**不**覆盖

- **生产负载：** 压力 / 并发 / 多租户。用 `tests/e2e/scenarios/`。
- **secret_key_base 轮换下的 token 安全：** 超出操作员视角。
- **Plugin install-by-name：** 还未实现（在 [`docs/futures/todo.md`](../futures/todo.md) 跟踪为 `esr daemon init/clear`）。
